Abstract: Long-sequence time series forecasting remains a key efficiency bottleneck for deep learning methods, and existing sparse attention designs tend to discard the positions most relevant to the prediction once the context is compressed. This paper proposes an adaptive sparse attention framework composed of hierarchical compression, learnable sampling, and local enhancement. The hierarchical compression module first aggregates the input sequence at multiple scales, which reduces the size of the attention matrix by one order of magnitude. The learnable sampling module then determines the set of critical positions from the query vector, and is trained end to end in a differentiable manner. Finally, the local enhancement module applies a lightweight convolution within adjacent windows so that short-term dependencies are preserved. We conduct rolling forecasting experiments spanning 5 years on 4 public benchmark datasets, and every configuration is repeated 5 times with the mean reported. Experimental results show that the framework achieves an average error accuracy of 19.5% with 1.2M trainable parameters, reducing the root mean squared error by 3.2 percentage points compared with the baseline, and cutting the training time of a single round by 25%. Further analysis indicates that the sampled critical position sets remain stable across datasets, which suggests that the proposed sampling strategy generalises well beyond the settings used for tuning. These findings demonstrate that adaptive sparse attention attains a more stable trade-off between accuracy and efficiency, providing a practical reference for long-sequence modelling under limited computational resources.
Keywords: time series forecasting; sparse attention; Transformer; efficiency optimisation
